# 动画包

每个形态一个目录：`normal`、`dark`、`duo`、`form4`、`form5`。

## 已经放进来的

v0.1 有三形态的待机和点击，都是按原型构图重画的静帧序列，不是官方立绘：

- `normal/idle/01.png` 睁眼，`02.png` 眨眼
- `normal/click/01.png` 被点到时的反应
- `dark/`、`duo/` 同样两套

播放器会把两帧待机排成「睁眼、睁眼、睁眼、眨眼」。点击序列只播一遍，然后回到待机。点击不改工作状态，也不改形态。

还没有单独文件的状态（思考、工作、等待、完成、出错）先沿用这一形态的待机图。状态条照常变。

## 以后怎么加

参考图放在 `packs/sakura/reference/`，这个目录里的图片不进仓库。看旁边的 `reference/README.md`。

动作可以用两种放法，播放器都会认：

1. 序列目录：`animations/<形态>/<动作>/01.png`、`02.png`…… 也接受 webp、gif。按文件名排序。
2. 单个文件：`animations/<形态>/<动作>.webm`（或 gif、png、webp、mov）。

动作名：

- `idle` `thinking` `working` `waiting` `success` `error` 跟工作状态走
- `click` 只在用户点到桌宠、并且没有拖动时播

不要用 `normal`、`dark`、`duo` 当动作名。那会被接口拒绝，避免把换形态当成一个动作。

换上文件后，设置里点「重新扫描」，或者等目录监视自己发现。窗口是透明的，素材最好带透明通道。
