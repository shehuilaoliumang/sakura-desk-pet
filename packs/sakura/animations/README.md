# 动画包

每个形态一个目录：`normal`、`dark`、`duo`、`form4`、`form5`。

## 已经放进来的

v0.1 有三形态的待机和点击，都是按原型构图重画的静帧，不是官方立绘：

- `normal/idle/01.png` 睁眼，`02.png` 眨眼
- `normal/click/01.png` 被点到时的害羞笑脸。喜用这一张，没有另开目录
- `dark/`、`duo/` 同样是睁眼、眨眼、害羞笑脸

播放器把待机排成「睁眼、吸气、呼气、眨眼」。呼吸是画面上的轻轻起伏，不是新画的帧。点击不改工作状态，也不改形态。

## 这一轮加上的表情

还是同一套立绘，只让脸和一点点位置变掉。每个新目录有两张：`01.png` 是表情，`02.png` 是同一张往旁边或上下挪过的，用来让动作读出来。

| 目录 | 情绪 | 三形态 |
| --- | --- | --- |
| `angry/` | 怒 | 常态樱、黑樱、双人（黑樱皱眉，常态樱保持原来的神情） |
| `sad/` | 哀 | 常态樱、黑樱、双人（常态樱低下眼） |
| `sad-dark/` | 哀 | 只有双人。黑樱低下眼，常态樱保持原来的神情 |
| `joyful/` | 乐 | 常态樱、黑樱、双人（常态樱笑出声，黑樱仍是平静的） |

喜没有新文件，点头、鞠躬、把苹果递出去，都播原来的 `click/01.png`，中间夹一帧原来的眨眼。

思考、工作、等待仍用待机的眨眼和呼吸，只是头会偏一点、节奏不一样。完成播一次喜，然后在那张笑脸上继续呼吸。出错时，常态樱用哀；黑樱用怒；双人看黑樱占比，一半及以上用怒，不到一半用哀。

## 以后怎么加

参考图放在 `packs/sakura/reference/`，这个目录里的图片不进仓库。看旁边的 `reference/README.md`。

动作可以用两种放法，播放器都会认：

1. 序列目录：`animations/<形态>/<动作>/01.png`、`02.png`…… 也接受 webp、gif。按文件名排序。
2. 单个文件：`animations/<形态>/<动作>.webm`（或 gif、png、webp、mov）。

动作名：

- `idle` `thinking` `working` `waiting` `success` `error` 跟工作状态走。立绘播放时，思考、工作、等待用待机的眨眼和呼吸；完成和出错会改播喜、怒或哀。
- `click` 是原来的害羞笑脸。喜的点头、鞠躬、递苹果用它。
- `angry` `sad` `joyful` 是怒、哀、乐的表情。`sad-dark` 只在双人里给黑樱用。

不要用 `normal`、`dark`、`duo` 当动作名。那会被接口拒绝，避免把换形态当成一个动作。

换上文件后，设置里点「重新扫描」，或者等目录监视自己发现。窗口是透明的，素材最好带透明通道。
