# 像素Q

全身像素 Q 版，三形态各一套短循环。画面是从已定稿的原创重绘上抠下来的，不是程序画的圆块，也不是官方立绘。

已定稿的动作是 8 帧。待机用站立定稿踮脚，喜把苹果递出去，怒会甩手摇头，哀会蹲下去，乐会先蹲再跳。常态樱和黑樱的挥手、点头、拒绝、转圈、坐下、睡觉、伸懒腰、吃惊、害羞、捉弄、张望、咬苹果、抛苹果、拍手、跳舞、摸头、笑、思考、工作、等待也是定稿帧。双人默认是站着一起捧苹果。坐着看书在 `sit` 和 `book`。`lean` 是两人相靠。双人其余新姿势还没有单独稿，名单在上一级的 `MOTIONS.md`。

点头发、脸、蝴蝶结、手、苹果、衣服或脚，播对应的动作，并说一句给用户听。点击不改工作状态，也不改形态。
